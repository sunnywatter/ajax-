# 极简AJAX图书管理系统

一个基于原生JavaScript和localStorage的极简图书管理系统，实现了完整的CRUD操作。

## 功能特性

- ✅ **图书展示** - 页面加载时自动获取并显示图书列表
- ✅ **添加图书** - 通过表单添加新图书
- ✅ **搜索图书** - 按书名或作者搜索图书
- ✅ **编辑图书** - 在线编辑图书信息
- ✅ **删除图书** - 删除指定图书
- ✅ **状态反馈** - 实时显示操作状态和错误信息

## 技术栈

- **前端**: HTML5 + CSS3 + 原生JavaScript (ES6+)
- **数据存储**: localStorage (本地存储)
- **数据格式**: JSON

## 快速开始

### 直接运行

**无需安装任何依赖！** 直接用浏览器打开 `index.html` 文件即可运行。

### 如何使用

1. **打开页面**: 用任意现代浏览器打开 `index.html`
2. **查看图书**: 页面自动显示预设的图书列表
3. **开始操作**: 可以添加、搜索、编辑和删除图书

## 核心功能说明

### 查看图书
- 页面加载后自动从本地存储获取并显示图书列表
- 表格清晰展示图书的ID、书名、作者、出版社信息

### 添加图书
1. 在"添加新图书"区域填写完整信息
2. 点击"添加图书"按钮
3. 系统自动验证输入并保存
4. 表单自动清空，列表实时更新

### 搜索图书
1. 在搜索框输入关键词（书名或作者）
2. 点击"搜索"按钮或按回车键
3. 列表显示匹配的图书
4. 点击"重置"按钮显示所有图书

### 编辑图书
1. 点击图书行右侧的"编辑"按钮
2. 原内容变为可编辑的输入框
3. 修改完成后点击"保存"
4. 点击"取消"放弃修改

### 删除图书
1. 点击图书行右侧的"删除"按钮
2. 在确认对话框中点击"确定"
3. 图书从列表中移除并从本地存储删除

## 技术特点

1. **纯原生实现** - 不使用任何第三方库
2. **本地存储** - 使用localStorage持久化数据
3. **模拟异步** - 保留延迟效果，模拟真实AJAX交互
4. **完善的错误处理** - 所有操作都有状态反馈
5. **响应式设计** - 适配不同屏幕尺寸
6. **输入验证** - 确保数据完整性

## 浏览器兼容性

- Chrome 43+
- Firefox 34+
- Safari 10+
- Edge 12+

## 数据持久化

所有数据都存储在浏览器的localStorage中：
- 关闭浏览器后数据不会丢失
- 清除浏览器缓存会删除数据
- 支持离线使用

## 开发说明

这个版本已经完全移除了对JSON Server的依赖，所有数据操作都在本地完成：

- 使用localStorage替代JSON Server
- 保留了异步操作的模拟（setTimeout）
- 实现了完整的CRUD操作
- 代码结构清晰，易于理解和扩展

## 故障排除

如果遇到问题：
1. 检查浏览器是否支持localStorage
2. 尝试清除浏览器缓存后重新打开
3. 检查浏览器控制台是否有错误信息
4. 确保JavaScript在浏览器中已启用
